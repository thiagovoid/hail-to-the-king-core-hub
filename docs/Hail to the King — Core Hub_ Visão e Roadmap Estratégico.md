# Hail to the King — Core Hub

## Visão Estratégica do Ecossistema da Guild

---

# 1. Visão

A Hail to the King nasceu em 2012, criada por um grupo de amigos com interesses em comum.

Ao longo dos anos, a guild se tornou uma comunidade formada por jogadores com diferentes níveis de experiência, com foco principal em PvE, progressão de Mythic+ e Raides, mas mantendo espaço para jogadores casuais e PvP.

A guild possui cinco pilares:

- Respeito
- Humildade
- Empatia
- Companheirismo
- Amizade

O Core Hub deve transformar esses valores em uma experiência digital.

O objetivo não é criar apenas um site institucional.

O objetivo é criar um **ecossistema da Hail to the King**.

---

# 2. O Core Hub como Ecossistema

O projeto deve possuir três componentes principais:

Responsável por:

Responsável por:

- notificações

- comunicação
- integração com o Core Hub

### Discord

Responsável pela comunicação em tempo real e convivência da comunidade.

# 3. Objetivos do Projeto

O Core Hub deve atender seis objetivos principais:

## 3.1. Atrair novos jogadores

Criar uma experiência que faça um jogador pensar:

> "Essa guild parece organizada e divertida. Quero fazer parte."

---

## 3.2. Ensinar jogadores

Criar uma verdadeira academia da guild.

O jogador deve encontrar informações para melhorar:

- sua classe
- sua spec
- sua rotação
- suas mecânicas
- seus equipamentos
- suas decisões
- sua performance

Integrar dados de:

- Warcraft Logs
- Wipefest
- WoW Analyzer

- Raider.IO
- futuras ferramentas

Transformar dados em:

- métricas
- avaliações
- metas
- recomendações

---

## 3.4. Aumentar a atividade da comunidade

Criar motivos para os membros visitarem o site mesmo quando não estão em raid.

Exemplos:

- eventos
- quizzes
- rankings
- premiações
- notícias
- conteúdo
- desafios
- conquistas

# 7. Sistema de Performance

## Objetivo

Unificar ferramentas externas.

---

## Providers

Cada ferramenta deve possuir um provider independente.

```text
Warcraft Logs
Wipefest
WoW Analyzer
Raidbots
Raider.IO
Archon
Future Tools
```

Arquitetura:

```text
Provider
    ↓
Raw Data
    ↓
Normalization
    ↓
Canonical Metrics
    ↓
Performance Engine
    ↓
Goals
    ↓
Assessment
```

Adicionar uma nova ferramenta deve significar adicionar um novo Provider, sem alterar o restante do sistema.

---

# 7.1. Métricas

- DPS
- HPS

# 7.2. Separação de conceitos


```text
Meta atingida.
```

# 23. Princípio de Extensibilidade

Nunca criar dependência direta:

```text
Página → Warcraft Logs
```

Preferir:

```text
Warcraft Logs
      ↓
Provider
      ↓
Normalized Data
      ↓
Core Hub
```

Se amanhã surgir uma ferramenta melhor:

```text
Nova ferramenta
      ↓
Novo Provider
      ↓
Core Hub
```

O restante da aplicação continua funcionando.

# 24. Filosofia do Produto

O Core Hub deve evitar transformar a guild em uma empresa.

Performance deve ser usada para:

- ensinar
- orientar
- reconhecer
- melhorar

Não para:

- humilhar
- punir
- criar pressão desnecessária

O sistema deve incentivar:

> "Como posso ajudar esse jogador a melhorar?"

e não:

> "Quem é o pior jogador?"

# 26. Estratégia de Recrutamento

O site deve funcionar como uma máquina de aquisição de jogadores.

Fluxo:

```text
YouTube / Twitch / Google / Discord
                 ↓
              Website
                 ↓
         "Conheça a Guild"
                 ↓
          História + Cultura
                 ↓
       Performance + Progressão
                 ↓
            Comunidade
                 ↓
             Eventos
                 ↓
           Recrutamento
                 ↓
              Trial
                 ↓
              Membro
```

O principal objetivo é fazer com que um jogador de outro server consiga entender:

1. Quem somos.
2. Como jogamos.
3. O que valorizamos.
4. O que podemos oferecer.
5. Como ele pode participar.

- criadores de conteúdo
- eventos

# 30. Princípio Final

A Hail to the King não deve competir apenas por progressão.

Deve competir por **experiência de comunidade**.

Progressão pode ser encontrada em muitas guilds.

Um bom ambiente pode ser encontrado em muitas guilds.

Mas uma guild que possui:

- história
- identidade
- educação
- performance
- eventos
- criadores
- reconhecimento
- comunidade
- ferramentas próprias
- e um ecossistema digital integrado

é muito mais difícil de encontrar.

O Core Hub deve ser a materialização digital dos pilares da Hail to the King:

**Respeito.  
Humildade.  
Empatia.  
Companheirismo.  
Amizade.**

E transformar esses valores em uma experiência que faça alguém pensar:

> **"Eu quero fazer parte disso."**
